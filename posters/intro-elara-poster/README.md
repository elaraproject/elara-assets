# Introduction to Project Elara Poster Assets

This is a guide to the assets stored within this folder.

## Our assets

The TikZ drawings are our own work. Both light-themed and dark-themed versions of each of the diagrams are available and can easily be adjusted in the provided TeX code. They can be compiled using a suitable modern version of LaTeX ([Overleaf](https://www.overleaf.com/) is convenient for this purpose). The SVGs are created from the LaTeX-outputted PDFs, imported into [Inkscape](https://inkscape.org/), and then slightly fine-tuned for a transparent background. For fully reproducible results, the following versions of LaTeX on Overleaf were used:

- TeX Distribution: TeX Live 2024
- Compiler: pdfLaTeX

## Used external assets

All external assets come from the public domain:

- Icons are by [Andrej Pancik](https://github.com/apancik)'s collected set of public domain icons (this is its [GitHub repository](https://github.com/apancik/public-domain-icons/))
- Model of the 70m Deep Space Network antenna from NASA (can be found on [NASA's 3D resources catalog](https://nasa3d.arc.nasa.gov/detail/jpl-vtad-dsn70) with a copy (as far as we know?) at [NASA's science resources website](https://science.nasa.gov/resource/deep-space-network-70-meter-antenna-3d-model/). We have added the Blender 3D model from the former and the glTF model from the latter. Given that NASA is a government agency its content should _in theory_ be public domain.

We graciously thank both NASA and Andrej for their generous sharing of their work.
