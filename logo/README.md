# Project Elara Logos

This folder contains the official logos of Project Elara. The two logos in this immediate directory are the shortened logos, whereas the `elara-full-logo/` folder contains the full-length logos (including our logotype). They are utilized in Project Elara promotional materials, official publications (including our website and Handbook), and to represent the Project publicly in all other capacities.

## Information

Logos were created in [Figma](https://figma.com) and [Inkscape](https://inkscape.org), but all have been converted to SVGs that should be fully Inkscape-compliant. There are also exported PNGs for other uses. Both variations suitable for light and dark backgrounds are available

## Usage

We welcome using the Project Elara logos **provided you do not use the logos in a way to mis-label something not part of the Project as an official release, publication, or work done by the Project**. That is to say, don't try to make your own work seem like something from Project Elara by putting our logo on it. You can _adapt_ the logo, that is fine, although adapt it in a way that makes it sufficiently visually distinct from the Project so as not to be confused with our work. Otherwise, these logos are open-source, and you are free to re-use them and let your creativity run free!
